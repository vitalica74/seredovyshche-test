Перемістити проєкт у кошик?
Проєкт можна буде відновити. Але кошик зберігається тільки в даних цього браузера. Експорт ZIP необов’язковий. Кошик зберігає файли проєкту, але не створює резервну копію IndexedDB. Дані запущеної програми не очищаються.

Інтерфейс 0.1.18.3 · Web Runtime · Тестова
Локальна платформа для HTML, CSS та JavaScript-програм.
Експорт ZIP зберігає файли вибраної програми, але не містить її IndexedDB. Дані експортуйте окремо всередині програми, якщо вона це підтримує.
Інструкція: оберіть програму, натисніть «▶ Запустити». У браузері запускається ізольований Web Runtime без постійного сховища програми; на Android — окремий WebView. Для перенесення її файлів використовуйте «Експорт ZIP». Не очищуйте дані Android-застосунку без перевіреної резервної копії.
Оновлення: встановлюйте підписаний release APK поверх наявного застосунку. Автоматична перевірка оновлень ще не реалізована.
